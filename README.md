# Aloy Mohajan — Portfolio + Games Hub (v2)

Responsive static website with:
- Premium dark portfolio layout
- About, portfolio, FedarDokan brand and WhatsApp contact sections
- Games section with category filters
- Browser-only game manager for adding hosted game URLs or small single-file HTML demos

## Preview
Open `index.html` in a modern browser.

## GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Important limitation
The included game manager is a front-end prototype. Games added through it are saved only in localStorage in the current browser/device; they are NOT uploaded to GitHub or shared with all visitors. Sample game cards are placeholders, not playable games.

For a real public admin panel where an administrator can upload HTML5 game ZIPs and every visitor sees the new games, connect authentication plus database/file storage (e.g. Supabase Storage + database) and add server-side validation. Do not treat a client-side manager as secure admin authentication.
